# 中文释义粤语点读

本功能沿用现有英汉词库。英文继续使用原有发音，中文释义可使用浏览器提供的粤语声音。IELTS 是本次验收词库，其他英汉词库也可使用。

## 本地启动

首次安装依赖时运行

```powershell
npx -y yarn@1.22.22 install --frozen-lockfile --cache-folder .yarn-cache
```

以后在项目目录运行

```powershell
node .\node_modules\vite\bin\vite.js --host 127.0.0.1 --port 5173 --strictPort
```

浏览器打开 [http://127.0.0.1:5173](http://127.0.0.1:5173)。本机已经安装 Yarn 1 时，也可直接使用 `yarn install --frozen-lockfile` 和 `yarn start`。

## 启用粤语

先在词库页选择 IELTS。打开音效设置，在释义发音区域开启发音，把模式改成粤语。选择一个声音后点击试听粤语。声音、音量和释义语速会保存在当前浏览器。

回到学习页后，点击中文释义旁的紫色喇叭即可点读。左侧 List 打开本章词表。每行紫色喇叭朗读中文释义，灰色喇叭保留英文发音。

第一版只提供点读。英文、粤语与下一词的自动连续播放留待后续实现。

## 声音与故障提示

粤语模式只接受浏览器返回的粤语候选。常见语言标签包括 `yue`、`zh-yue`、`zh-HK` 和 `zh-Hant-HK`。普通话声音不会进入候选，也不会在粤语失败时接管播放。

声音列表可能在页面打开后才加载。设置页会监听浏览器的声音变化，也可点击重新读取。保存的声音消失时，页面会要求重新选择。

没有候选时，可在 Windows 语言设置中添加香港粤语及语音组件。安装后完全退出浏览器，再重新打开本地页面并点击重新读取。系统显示已经安装，仍需以网页中的声音列表和试听结果为准。

标为本地声音的项目来自 `localService=true`。在线声音需要网络。原有英文发音也使用网络音频。
